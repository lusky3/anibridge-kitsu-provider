# Security Policy

## Reporting a Vulnerability

We take the security of `anibridge-kitsu-provider` seriously. If you discover or suspect a security vulnerability, please report it privately via GitHub's Private Vulnerability Reporting feature:

1. Go to the repository's [Security Advisories](https://github.com/lusky3/anibridge-kitsu-provider/security/advisories) page.
2. Click **"Report a vulnerability"** to submit a private draft advisory.
3. Include details of the vulnerability, steps to reproduce, potential impact, and any suggested remediation.

Please **do not** open public issues or discussions for security vulnerabilities until they have been reviewed and addressed.

## Supported Versions

Only the latest release of `anibridge-kitsu-provider` receives active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
